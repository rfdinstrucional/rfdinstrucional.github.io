## Sobre o Projeto

PowerUp! Software é a segunda fase do jogo STEAM, dedicada à introdução de lógica de programação. O personagem precisa hackear terminais, escrever scripts e resolver puzzles lógicos para desbloquear portas e restaurar sistemas da cidade. Cada puzzle ensina conceitos reais de programação dentro de uma narrativa envolvente.

## Metodologia

A fase foi desenhada com base em Computational Thinking e Parsons Problems — o aluno primeiro organiza blocos de código, depois escreve código próprio. A progressão segue Bloom: identificar → entender → aplicar → criar. Cada puzzle é um mini-exercício de debugging e resolução de problemas.

## Conhecimentos Envolvidos

- Variáveis, tipos de dados e operadores
- Estruturas condicionais (if/else)
- Loops e repetição
- Funções e modularização
- Depuração e resolução de problemas

## Solução Técnica

Continua a engine de Three.js do Hardware, mas com interface de terminal interativo sobreposta ao mundo 3D. O editor de código usa Monaco Editor (mesmo do VS Code) com syntax highlighting e validação em tempo real. Soluções são testadas contra test cases antes de avançar.

## Resultado

Fase testada com 90 alunos que completaram o módulo Hardware. A evolução na capacidade de resolver problemas com lógica de programação foi substancial. 82% dos alunos relatam confiança para escrever código após a experiência.
