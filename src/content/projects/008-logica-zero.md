## Sobre o Projeto

Lógica Zero é um curso de lógica de programação para iniciantes absolutos, hospedado no Moodle. O curso ensina pensamento computacional usando Python como veículo, mas o foco real está na lógica — estruturas de decisão, repetição, funções e resolução de problemas — não na sintaxe.

## Metodologia

Desenhado com abordagem de Constructionism (Papert): o aluno aprende fazendo. Cada aula inclui um mini-projeto que o aluno constrói do zero. O curso utiliza Parsons Problems (código embaralhado que o aluno reorganiza) antes de permitir escrita livre, reduzindo a barreira de entrada para iniciantes.

## Conhecimentos Envolvidos

- Variáveis, tipos de dados e operadores
- Estruturas condicionais (if/else)
- Loops (for, while)
- Funções e modularização
- Depuração e resolução de problemas

## Solução Técnica

Moodle com atividades de código integrado (CodeRunner), quizzes adaptativos, vídeos curtos (5-10min) com screencast, e exercícios progressivos. Cada módulo termina com um mini-projeto que combina todos os conceitos aprendidos. Peer review incentivado para desenvolver habilidade de leitura de código.

## Resultado

Curso com 8 módulos, 64 aulas (24h), 48 exercícios práticos e 8 projetos avaliativos. A evolução medida por pré/pós-teste mostrou ganho significativo na capacidade de resolver problemas com lógica de programação. 82% dos concluintes relatam confiança para aprender qualquer linguagem.

## About the Project

Web Skill up! is a programming logic course for absolute beginners, hosted on Moodle. The course teaches computational thinking using Python as a vehicle, but the real focus is on logic — decision structures, repetition, functions, and problem-solving — not syntax.

## Methodology

Designed with a Constructionist approach (Papert): students learn by doing. Each lesson includes a mini-project built from scratch. The course uses Parsons Problems (shuffled code that students reorganize) before allowing free writing, reducing the barrier to entry for beginners.

## Knowledge Areas

- Variables, data types, and operators
- Conditional structures (if/else)
- Loops (for, while)
- Functions and modularization
- Debugging and problem-solving

## Technical Solution

Moodle with integrated code activities (CodeRunner), adaptive quizzes, short videos (5-10min) with screencasts, and progressive exercises. Each module ends with a mini-project combining all concepts learned. Peer review encouraged to develop code reading skills.

## Results

Course with 8 modules, 64 lessons (24h), 48 practical exercises, and 8 assessed projects. Pre/post-test measurement showed significant improvement in problem-solving with programming logic. 82% of completers report confidence to learn any language.
