## Sobre o Projeto

O Void Terminal é uma experiência interativa de terminal construída com WebGL e shaders customizados. O projeto explora a estética de terminais retrô com iluminação dinâmica e animação tipográfica em tempo real.

## Desafio

Criar uma interface de terminal que fosse visualmente impressionante sem perder a usabilidade. Cada caractere precisava ter comportamento próprio enquanto mantinha a performance em 60fps.

## Solução

Utilizando GLSL para shaders customizados e WebGL para rendering de alta performance, cada caractere é renderizado como uma entidade individual com propriedades de cor, brilho e animação. O sistema de partículas integrado cria efeitos visuais reativos à digitação.

## Resultado

Uma experiência visual única que combina nostalgia de terminais antigos com tecnologia moderna. O projeto foi apresentado em conferências de creative coding e gerou discussão sobre o potencial do WebGL em interfaces não convencionais.
