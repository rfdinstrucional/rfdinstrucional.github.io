## Sobre o Projeto

O Grid Engine é um sistema de layout procedural para experimentos de design generativo. Ele gera composições visuais baseadas em regras paramétricas, permitindo criação infinita de layouts grid com variações controladas.

## Desafio

Manter flexibilidade criativa enquanto garantia que os layouts gerados sempre respeitassem princípios de hierarquia visual e balanceamento, independentemente dos parâmetros de entrada.

## Solução

Desenvolvido em TypeScript com rendering em Canvas 2D, o engine implementa algoritmos de packing retangular com prioridade e peso. Os parâmetros incluem colunas, gap, proporções, paleta de cores e regras de agrupamento.

## Resultado

Uma ferramenta que gera centenas de composições únicas por sessão, utilizada como base para experimentos de design e prototipagem rápida de layouts para web e impressão.
